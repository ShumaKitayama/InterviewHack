# commit

変更点をすべてステージングし、コミットメッセージを入力してコミットします。

- 変更点をすべてステージング
- コミットメッセージを入力
  - `.cursor/rules`及び`Agent.md`内にコミットメッセージのルールがあればそれに従う
  - なければ下記ルールに従ってコミットメッセージを入力する
    - 必ず動詞で始める（例：Add、Fix、Update、Change、Docs、Style、Feature、Refactor など。）
    - メッセージは 50 文字以内 に収める
    - 命令形 で書く（例：「Added」ではなく「Add」）
    - 具体的かつ簡潔に 記述する
    - 文末に 。 は付けない
    - 言語は常に日本語を使用する
- コミット
