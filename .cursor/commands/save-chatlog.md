# save-chatlog

ここまでのチャット履歴を全てを把握して下記に臨むこと。

1. チャット履歴から、与えられた指示内容やタスク、それに沿って実施した修正内容や提案をまとめる。
2. まとめたものを単一のレポートファイルとして次のファイル形式に沿って保存する。
   　
   - `yyyy-mm-dd=log(n).md`
     - yyyyは現在の西暦、mmは現在の月、ddは現在の日、nは未使用で最小のナンバー。例えば既に`2026-02-17=log(1).md`があったとしたら、次に生成するのは`2026-02-17=log(2).md`となる。日付が変わったらナンバリングは初期化され`2026-02-18=log(1).md`のように使用できる。
3. ファイルは `ai_message_log`という名のディレクトリに保存すること。
