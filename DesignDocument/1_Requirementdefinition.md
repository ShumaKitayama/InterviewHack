# 1. 要件定義

> 改訂：2026-10-22。方針転換メモ（`DirectionChange_20261022.md`）の決定事項 D1〜D16 を反映した。

## 1.1 機能要件

### 1.1.0 共通：AI連携（コピペ方式）

本アプリは LLM の API を呼ばない（D7）。AI を使う機能は、すべて次の流れで実現する。以降の章では、この流れを「**AI連携**」と呼ぶ。

1. **プロンプト生成**：アプリが、自己資産（セット1）、企業情報（セット2）、ユースケースごとのテンプレートからプロンプトを組み立てる
2. **外部AIでの実行**：ユーザーが iOS の共有シートやクリップボードを使い、ChatGPT・Gemini などに渡す。AI はユーザー自身のアカウントで使い、無料版でもよい
3. **回答の取り込み**：ユーザーが回答をアプリに貼り戻す。アプリは回答を解析してプレビューを表示し、ユーザーが確認・修正してから保存する（D10）

共通要件：

- プロンプトに使う自己資産と企業研究資料は、ユーザーが選ぶ
- 構造化が必要なユースケース（想定Q&A生成、面接ログ添削、企業研究資料の要約）は、目印付きテキスト形式で出力するよう AI に指示し、回答を解析する。解析できなかった部分は、プレビュー上で手動修正できる
- ES ドラフト、ES 推敲、ダッシュボード要約は解析せず、全文をそのまま取り込む
- 未完了の AI連携（プロンプトは作ったが、まだ回答を貼り戻していないもの）は、あとから再開できる（D13）

### 1.1.1 認証・アカウント

- ユーザー登録（メールアドレス＋パスワード）
  - Google ログインは追加候補。Sign in with Apple は Apple Developer Program 加入後に追加する（D5）
- ログイン / ログアウト
- パスワードリセット
- アカウント削除（退会）
  - 退会すると、ユーザーのデータ（共有リンクを含む）は即時に削除される。アカウントの記録は、メールアドレスと表示名を消したうえで残す（詳細は 6.3.3）

### 1.1.2 自己資産DB（セット1）

- 自己資産の登録
  - 種別例：ガクチカ、職務経歴、プロジェクト、強み、弱み、スキル、エピソード、成果
- 自己資産の編集 / 削除
- タグ付け（複数可）
- 検索・フィルタ（タグ、キーワード）
- 並び替え（作成日、更新日、よく使う など）
- AI連携のプロンプトに含める自己資産の選択

### 1.1.3 企業DB（セット2）

- 企業情報の登録
  - 企業名、職種、選考フェーズ、志望動機メモ、URL、自由メモ
- 企業研究資料の管理（D11）
  - URL の取り込み：アプリ内でページを開き、本文を抽出する。抽出した本文はプレビューで編集してから保存する
  - PDF の取り込み：端末上でテキストを抽出する
  - スキャンPDF・画像の取り込み：端末上で文字認識（OCR）する
  - 保存するのは抽出したテキストだけで、ファイル本体は保存しない
  - エゴサ情報のメモ化
  - 資料の要約（AI連携）
- 編集 / 削除
- 検索・フィルタ
- 過去の面接履歴との紐付け表示

### 1.1.4 ES作成支援ルーム（ES作成・推敲）

- ESプロジェクト作成
  - 企業・職種の選択（企業DBと連携）
  - 提出期限、ステータス管理（未着手、作成中、添削中、完了、提出済）
- ESセクション管理
  - 項目設定（志望動機、自己PR、ガクチカ、長所・短所など）
  - 文字数制限の設定
- ドラフト作成（AI連携：セット1＋セット2の統合）
  - 自己資産（セット1）と企業研究資料（セット2）を選び、ドラフト作成用のプロンプトを生成する
  - 「興味を持った点」と「自分の強み」を論理的に接続するよう指示する
- 推敲・添削ループ（AI連携）
  - 取り込んだ文章の編集
  - 「もっと具体的に」「結論ファーストで」などの指示を加えた推敲用プロンプトの生成
  - バージョン管理（履歴の保持）
    - 版を残すのは、AI連携の取り込みで本文を上書きする直前と、ユーザーが「この版を保存」を押したときの2つだけ
    - 1セクションあたり最新20件まで保持する
    - 版の一覧から、任意の版との差分を見られ、その版に戻せる（戻す直前の本文も版として残す）
- 外部出力
  - テキストコピー、PDF出力
  - 共有リンクの発行（友人・メンターへの確認依頼用）（D12）
    - ESプロジェクト単位で発行し、公開するセクションを選べる
    - 発行時点の内容のスナップショットを公開する（以後の編集は反映しない）
    - リンクを知っていれば、ログインなしで閲覧できる（閲覧のみ）
    - 有効期限は 1日 / 7日 / 30日 から選ぶ（初期値は7日、無期限は不可）。いつでも失効できる
    - ユーザー名は表示しない。企業名を表示するかどうかは発行時に選ぶ

### 1.1.5 面接対策ルーム（事前対策）

- 対象企業・職種の選択
- 自己資産DBと企業DBを元にした、想定質問リスト生成用のプロンプトの生成（AI連携）
- 各質問に対する「自分専用の模範解答」も、同じプロンプトで依頼する
- 取り込んだ結果の保存（Q&Aバンクへ）
- 条件を変えたプロンプトの再生成

### 1.1.6 面接振り返りルーム（事後対策）

- 面接ログの入力
  - 実際に聞かれた質問
  - 自分の回答
- 添削・フィードバック（AI連携）
  - 論理性、具体性、説得力などの観点での指摘
  - 改善案の提示（自己資産を参照）
- フィードバック結果の保存
- 次回用の「改善済み回答案」の保存

### 1.1.7 Q&Aバンク（復習機能）

- これまでに保存したQ&Aの一覧表示
- 検索・タグフィルタ
- お気に入り（一覧の先頭に表示し、絞り込みにも使える）
- スワイプ or リスト形式での復習UI
- 復習済み / 未復習のステータス管理
- オフラインでも閲覧・復習できる（D16）

### 1.1.8 ダッシュボード

- 直近の面接予定（手動登録ベース）
- 「次に直すべきポイント要約」の表示（AI連携で取り込んだもの）
- 最近追加したQ&A / 面接ログへのショートカット
- 未完了の AI連携の一覧（続きから貼り戻す）

## 1.2 非機能要件

### 1.2.1 性能要件

- 通常画面遷移は2秒以内に表示完了
  - サーバー復帰の待ち時間（Neon のコールドスタート）中は、キャッシュ済みのデータを先に表示する
- 一覧検索・フィルタは体感遅延が出ないこと
- プロンプト生成と回答の解析は、それぞれ2秒以内に完了すること

### 1.2.2 可用性・信頼性

- ユーザーデータ（自己資産、面接ログ、Q&A）は永続化される
- バックエンド障害時にもデータ破損が起きない設計
- 入力途中の下書き（面接ログ、編集中のES）は端末に保存し、通信できない場合も失われない。オンライン復帰後、ユーザーの操作で送信する（自動送信はしない）（D16）
- 回答の解析に失敗しても、貼り戻した内容は失われず、手動修正で保存できる

### 1.2.3 セキュリティ

- 通信のHTTPS必須
- ユーザーごとのデータ分離（他人のデータは参照不可）。認可はすべてバックエンドで行う（D6）
- 個人情報・職歴・面接内容を扱うため、アクセス制御を厳密に行う
- シークレットはクライアントに埋め込まない
- 共有リンクのトークンは推測不可能にし、サーバーにはハッシュだけを保存する（D12）
- 端末内のキャッシュは iOS の Data Protection で保護し、ログアウト・退会時に削除する（D16）

### 1.2.4 プライバシー

- ユーザーの入力データは本人のみが閲覧可能（ユーザー自身が発行した共有リンクを除く）
- AI連携では、ユーザーが自分の操作で外部AIサービスにデータを渡す。アプリはその旨と注意点を明示する
  - 運営側のサーバーは外部AIサービスにデータを送らない
- プロンプトの全文と、貼り戻した回答の生データはサーバーに保存しない（D13）
- 退会時にデータ削除できること

### 1.2.5 運用・保守性

- エラーログを取得できる（Cloud Run の構造化ログ）
- テンプレートのバージョンごとに、回答の解析成功率と離脱率を集計できる（D15）
- テンプレートを変更しても、古いバージョンの形式の回答を解析できる（D10）
- 将来の機能追加（音声入力、高度分析、端末上のLLMによるワンタップ生成）に耐えられる構成

### 1.2.6 コスト制約

- 運営費はほぼ0円とする（各サービスの無料枠内で運用する）
  - API：Cloud Run、DB：Neon、認証：Firebase Auth
- LLM の API 費用は発生させない（D7）
- 避けられない費用は、配布を始める段階での Apple Developer Program（年 $99）のみ

### 1.2.7 対応プラットフォーム

- iOS（iPhone）のみ（D1）。Android と Web アプリは対象外
- 配布は当面、開発者本人の iPhone のみ（D2）
- 共有リンクの閲覧ページのみ、Web ブラウザで表示する

## 1.3 スコープ定義（要件の境界）

### 1.3.1 MVPに含める

- 認証（メールアドレス＋パスワード）
- 自己資産管理
- 企業管理
- 企業研究資料管理（URL / PDF / 画像の取り込み、メモ）
- ES作成支援（ドラフト作成・推敲の AI連携）
- ESの共有リンク（閲覧のみ）
- 想定Q&Aの AI連携
- 面接ログ入力と添削の AI連携
- Q&Aバンクによる復習（オフライン閲覧を含む）
- 未完了の AI連携の再開

### 1.3.2 MVPでは含めない

- 課金・プラン（Free / Pro）・利用回数制限（D14）
- LLM の API 呼び出し、端末上のLLMによる生成（D7）
- 音声入力・文字起こし
- 共有リンクの閲覧者によるコメント、SNS的な共有機能（D12）
- 採用結果の分析・合否予測
- 企業データの自動クローリング（ユーザー操作による1ページ単位の取り込みは含める）（D11）
- 書き込みを含むオフライン同期（D16）
- Android / Web アプリ（D1）

## 1.4 前提・制約条件（要件レベル）

- AI を使う機能は、ユーザーが利用する外部AIサービス（ChatGPT・Gemini など）に依存する。外部サービスの回答品質や形式の揺れは、テンプレートと解析・手動修正で吸収する
- オフライン時は閲覧と下書き保存のみ可能。プロンプト生成・回答の解析・保存（下書きの送信を含む）にはネット接続が必要
- 個人開発・少人数運用を前提とし、無料枠のあるマネージドサービスを活用する
- 無料の Apple ID で開発するため、Sign in with Apple・iCloud・プッシュ通知は使えない。アプリは7日ごとに再インストールが必要
- 法的・倫理的に問題のある用途（経歴詐称支援など）は想定しない
