# 3. UX/UI設計

> 改訂：2026-10-22。方針転換メモ（`DirectionChange_20261022.md`）の決定事項 D1〜D16 と、2.10 の共通契約を反映した。
> iOS ネイティブアプリ（SwiftUI）を前提とする（D1）。課金・利用制限の画面と状態は削除した（D14）。

## 3.1 UX原則（このアプリの設計思想）

- 入力コスト最小：面接後の入力は「5分で終わる」ことを最優先
- 迷わせない導線：次にやるべき行動（対策 / 振り返り / 復習 / 未完了の AI連携の再開）が常に1つ提示される
- AI連携の往復を短く：プロンプトの受け渡しは共有シートかコピー1タップ、取り込みは貼り付け1タップで済ませる
- 透明性：外部AIに渡すプロンプトは、渡す前に確認・編集できる。取り込んだ結果には、根拠（使った自己資産）を表示する
- 失敗に強い：解析の失敗、アプリの終了、通信断があっても、作業内容が失われず、続きから再開できる
- 復習の継続性：面接直前に、オフラインでも「軽く眺める」だけで価値が出るUI
- iOS の慣習に従う：タブバー、ナビゲーションスタック、シート、スワイプ操作、Dynamic Type

## 3.2 情報設計（IA：Information Architecture）

### 3.2.1 グローバルナビ（タブバー）

iOS のタブバー（`TabView`）は 5 つまでとする。

- Home（ダッシュボード）
- 対策（面接対策ルーム / ES作成ルーム）
- 記録（振り返り：面接ログ）
- バンク（Q&A）
- データ（自己資産 / 企業）

設定は、Home のナビゲーションバー右上のボタンから開く。

## 3.3 画面一覧（Screen List）

MVPの主要画面を以下に定義する。

### 3.3.1 認証系

- S-Auth-01: ログイン（メールアドレス＋パスワード）
- S-Auth-02: 新規登録
- S-Auth-03: パスワードリセット
- S-Auth-04: 初回オンボーディング（最低限の自己資産入力誘導、AI連携の説明）

### 3.3.2 コア導線

- S-Home-01: ホーム（ダッシュボード）
- S-Prep-01: 面接対策ルーム（企業選択・材料の選択）
- S-Prep-02: 想定Q&Aの取り込み結果（質問リスト＋模範解答）
- S-ES-01: ESプロジェクト一覧（企業ごとのES管理）
- S-ES-02: ESエディタ（セクション構成・執筆・ドラフト作成の AI連携）
- S-ES-03: ES推敲（修正指示 → 推敲の AI連携 → 差分確認）
- S-ES-05: 版の履歴（一覧・差分・この版に戻す）
- S-ES-04: 共有リンク管理（発行・一覧・失効）
- S-Log-01: 面接一覧（面接単位の履歴）
- S-Log-02: 面接ログ入力（質問・回答）
- S-Log-03: 添削結果（改善案・改善版回答）
- S-QA-01: Q&Aバンク一覧
- S-QA-02: Q&A詳細
- S-QA-03: 復習UI（スワイプ/カード/単語帳）
- S-Data-01: 自己資産DB一覧
- S-Data-02: 自己資産作成/編集
- S-Data-03: 企業DB一覧
- S-Data-04: 企業作成/編集
- S-Data-05: 企業研究資料管理（資料一覧・要約確認）
- S-Data-06: URL取り込み（アプリ内ブラウザ → 本文抽出 → 編集）
- S-Data-07: PDF・画像取り込み（テキスト抽出 / OCR → 編集）

### 3.3.3 AI連携（共通）

- S-AI-01: プロンプト確認（全文の確認・編集、共有シート / コピー）
- S-AI-02: 回答の貼り戻し
- S-AI-03: 取り込みプレビュー（解析結果の確認・手動修正 → 保存）
- S-AI-04: 未完了の AI連携一覧（続きから再開）

### 3.3.4 設定

- S-Set-01: 設定トップ（アカウント情報、ログアウト）
- S-Set-02: （廃止）プラン管理。課金をしないため削除した（D14）
- S-Set-03: アカウント削除
- S-Set-04: AI連携とデータの扱い（外部AIに渡すデータの注意事項、端末内キャッシュの削除）

## 3.4 主要ユーザーフロー（User Flow）

### 3.4.0 AI連携の共通フロー

AI を使う機能は、すべてこのフローを通る（1.1.0）。

1. 材料を選ぶ（企業、自己資産、企業研究資料、面接ログなど）→「プロンプトを作る」
2. S-AI-01 プロンプト確認
   - プロンプトの全文を表示する（編集可）。長すぎる場合は警告と、「資料を減らす」「先に資料を要約する」の導線を出す（4.3.5）
   - 「共有」（共有シートで ChatGPT・Gemini などのアプリへ）または「コピー」
3. 外部AIのアプリで回答を得て、回答をコピーする
4. アプリに戻ると、S-AI-02 回答の貼り戻しが開く
   - クリップボードに新しいテキストがあれば「貼り付け」ボタンを強調する（iOS の貼り付け許可ダイアログに従う）
5. S-AI-03 取り込みプレビュー
   - 解析結果を項目ごとに表示し、各項目を編集・削除できる
   - `partial` の場合は欠けた箇所を、`failed` の場合は全文を1つの編集欄として表示する（4.3.7）
   - 警告（項目数の不一致、文字数の範囲外、（推測）の注記）を表示する
6. 「保存」→ 本来の画面（Q&Aバンク、添削結果、ESエディタなど）に戻る

途中でアプリが終了しても、セッションは S-AI-04 と Home から再開できる（D13）。

### 3.4.1 事前対策フロー（想定Q&A）

1. Home → 「面接対策を始める」
2. 企業選択（or 企業新規作成）＋職種確認
3. 使う自己資産と企業研究資料を選ぶ。質問数を選ぶ
4. AI連携の共通フロー（3.4.0）
5. 取り込み結果（S-Prep-02）を確認 → Q&Aバンクへ保存
6. 面接直前に復習UIで見返す（オフライン可）

### 3.4.2 ES作成フロー（企業研究→ドラフト→推敲）

1. Home → 「ESを作成する」
2. 企業選択（なければ作成）＋提出期限設定
3. 企業研究資料の取り込み（S-Data-06 URL / S-Data-07 PDF・画像）
   - 必要なら資料の要約（AI連携）で、特徴・求める人物像を整理する
4. ESセクション（志望動機、自己PRなど）を追加
5. ドラフト作成（AI連携）
   - 使う自己資産と企業研究資料を選ぶ
   - 取り込んだ本文が、セクションの下書きに入る
6. エディタで修正 ⇄ 推敲（AI連携。「もっと具体的に」などの指示を付ける）
7. 完成 → PDF出力 / テキストコピー / 共有リンクの発行（S-ES-04）

### 3.4.3 事後対策フロー（振り返り→添削→改善）

1. Home → 「面接を振り返る」
2. 面接選択（なければ面接作成：企業・日付・フェーズ）
3. 質問・回答を入力（複数件を連続登録できる。入力途中は端末に下書き保存される）
4. 添削する質問を選ぶ → AI連携の共通フロー（3.4.0）
5. 添削結果（S-Log-03）を表示（改善点＋改善版回答案）
6. 「改善版をQ&Aに登録」→ Q&Aバンクに蓄積

### 3.4.4 復習フロー（Q&Aバンク）

1. Home → 「復習する」
2. 復習対象の絞り込み（企業/タグ/未復習）
3. スワイプで確認（オフラインでも可）
4. 復習ステータス更新（復習済み/要再確認。MVP ではオンライン時のみ）

### 3.4.5 共有リンクフロー

1. ESエディタ（S-ES-02）→「共有リンクを作る」→ S-ES-04
2. 公開するセクションを選ぶ。有効期限（1日 / 7日 / 30日、初期値 7日）を選ぶ。企業名を表示するか選ぶ（初期値は表示しない）
3. 「発行」→ URL を表示し、共有シートで LINE などに送る
   - 発行時点の内容が固定されること、URL はこの画面でしか表示されないことを明示する
4. 失効したいときは、S-ES-04 の一覧から「無効にする」

## 3.5 画面遷移（State + Navigation）

### 3.5.1 Home（S-Home-01）

- 表示要素
  - 直近の面接（次の予定）
  - 「次回直すべきポイント要約」（最新の `dashboard_summaries`）。古い場合は「要約を更新する」（AI連携）
  - 未完了の AI連携（件数と最新の1件。タップで再開）
  - CTAボタン：対策を始める / 振り返る / 復習する
- 遷移
  - 対策 → S-Prep-01
  - 振り返り → S-Log-01 or S-Log-02
  - 復習 → S-QA-03
  - 未完了の AI連携 → S-AI-04 または該当セッションの S-AI-02
  - 設定（ナビゲーションバー）→ S-Set-01

### 3.5.2 面接対策ルーム（S-Prep-01）

- 入力要素
  - 企業選択（既存 or 新規）
  - 職種入力（企業に紐づくデフォルト可）
  - 使う自己資産（タグで絞り込み、前回の選択を初期値にする）
  - 使う企業研究資料（要約済みのものを優先表示）
  - 質問数（初期値 10）
- CTA
  - 「プロンプトを作る」
- 遷移
  - → S-AI-01（AI連携の共通フロー）
  - 入力不足 → 必須項目のハイライト

### 3.5.3 想定Q&Aの取り込み結果（S-Prep-02）

- 表示
  - 質問リスト（取り込んだ件数）
  - 各質問の模範解答（折りたたみ/展開）と、質問の意図（意図は取り込みプレビューでの確認用で、保存しない。4.2.1）
  - 使った自己資産（根拠の可視化：タイトル/タグ）
- 操作
  - 保存（S-AI-03 の確認後）
  - 条件を変えて作り直す（新しいセッションとして S-Prep-01 へ）
  - お気に入り（保存後の Q&A ごとに切り替え）
- 遷移
  - 保存 → S-QA-01 / S-QA-02

### 3.5.4 ESプロジェクト一覧（S-ES-01）

- 表示
  - 企業名、提出期限、進捗状況（未着手/作成中/添削中/完了/提出済）
  - ステータスで絞り込める（例：提出期限が近い「未着手」だけを表示）
  - ステータスはどの状態からでも変更できる。「提出済」を選ぶときだけ確認ダイアログを出す
  - 「新しいESを作成」ボタン
- 遷移
  - タップ → S-ES-02

### 3.5.5 ESエディタ（S-ES-02）

- レイアウト（iPhone）
  - 上部のセグメントで「ESセクション」と「企業研究資料」を切り替える
- 機能
  - 資料の取り込み（S-Data-06 / S-Data-07 へ）
  - セクション追加（文字数制限設定）。本文の文字数を常時表示する
  - 「ドラフトを作る」ボタン
    - 使う自己資産を選択（「学生時代に頑張ったこと」タグなど）
    - 参照する企業資料を選択（「経営理念」など）
  - 「共有リンク」ボタン → S-ES-04
  - セクションごとのメニュー
    - 「この版を保存」：今の本文を版として残す
    - 「版の履歴」→ S-ES-05
- 遷移
  - ドラフトを作る → S-AI-01 → … → 取り込み後、S-ES-02 に戻る
  - 推敲 → S-ES-03
  - 版の履歴 → S-ES-05

### 3.5.6.1 版の履歴（S-ES-05）

- 表示
  - 版の一覧（新しい順、最大20件）：保存日時、きっかけ（手動保存 / ドラフト / 推敲）、冒頭の数行
  - 選んだ版と今の本文との差分
- 操作
  - 「この版に戻す」：確認ダイアログのあと、戻す直前の本文を版として残してから本文を置き換える
- 遷移
  - 戻す / 閉じる → S-ES-02

### 3.5.6 ES推敲（S-ES-03）

- 表示
  - 現在のドラフト文章と文字数
- 操作
  - 修正指示の入力（候補チップ：「もっと具体的に」「結論ファーストで」「文字数を減らして」「熱意を強調して」）
  - 「推敲プロンプトを作る」→ S-AI-01
  - 取り込み時は、元の文章との差分を表示する（S-AI-03）
- 遷移
  - 確定 → S-ES-02（エディタに戻る）
  - 完成 → 出力メニュー（テキストコピー / PDF出力 / 共有リンク）

### 3.5.7 面接ログ入力（S-Log-02）

- 入力
  - 質問（テキスト）
  - 回答（テキスト）
  - 任意：自己評価/補足メモ
- 操作
  - 「質問を追加」（複数件登録）
  - 「添削する」
- 下書き：入力途中の内容は端末に保存し、オフラインでも失われない（D16）
- 遷移
  - 添削する → S-AI-01 → … → S-Log-03

### 3.5.8 添削結果（S-Log-03）

- 表示
  - 指摘（論理性/具体性/説得力/構成）
  - 改善案
  - 改善版回答案
  - 使用した自己資産（参照根拠）
- 操作
  - 改善版をQ&Aとして保存
  - もう一度添削（追加情報を入れて、新しいセッションで作り直す）
- 遷移
  - 保存 → S-QA-02

### 3.5.9 Q&A復習（S-QA-03）

- 表示
  - 1枚に「質問→タップで回答表示」
  - 企業名/タグ/作成日
- 操作
  - 次へ/前へ（スワイプ）
  - 復習ステータス更新（復習済み/要再確認）
  - お気に入り
- オフライン時も閲覧できる。ステータス更新はオンライン時のみ

### 3.5.10 プロンプト確認（S-AI-01）

- 表示
  - プロンプトの全文（編集可）、文字数
  - 外部AIに渡すデータの注意（初回は必ず表示。以後は折りたたみ。4.7）
  - 長すぎる場合の警告と導線（資料を減らす / 先に資料を要約する）
- 操作
  - 「共有」（共有シート）/「コピー」
  - 「回答を貼り付ける」→ S-AI-02
  - 「中止」（セッションを `abandoned` にする）

### 3.5.11 回答の貼り戻し（S-AI-02）

- 表示：貼り付け欄（複数行）、用途（例：「〇〇社 想定Q&A」）
- 操作
  - 「貼り付け」（クリップボードから）
  - 「プロンプトをもう一度見る」→ S-AI-01（`input_refs` から再生成）
  - 「取り込む」→ 解析 → S-AI-03

### 3.5.12 取り込みプレビュー（S-AI-03）

- 表示
  - 解析結果（use_case ごとの項目）と、解析状態（成功 / 一部のみ / 失敗）
  - 警告の一覧
  - ES推敲の場合は、元の文章との差分
- 操作
  - 項目の編集・削除、`failed` 時の手動分割
  - 「保存」→ 保存先の画面へ
  - 「貼り直す」→ S-AI-02

### 3.5.13 未完了の AI連携一覧（S-AI-04）

- 表示：用途、対象（企業名・ESセクションなど）、作成日時
- 操作
  - タップ → S-AI-02（続きから貼り戻す）
  - スワイプで「中止」（`abandoned`）

### 3.5.14 共有リンク管理（S-ES-04）

- 表示
  - 発行済みリンクの一覧（作成日時、有効期限、公開中 / 期限切れ / 無効）
  - 新規発行フォーム（公開するセクション、有効期限、企業名の表示）
- 操作
  - 「発行」→ URL の表示と共有シート（URL の再表示はできないことを明示する）
  - 「無効にする」（確認ダイアログあり）

### 3.5.15 URL取り込み（S-Data-06）

- 表示：URL 入力欄 → アプリ内ブラウザ（WebView）でページを表示
- 操作
  - 「本文を取り込む」→ 表示中のページの本文を抽出 → 編集画面
  - 編集画面でヘッダーや広告などの不要な部分を削除し、タイトルを付けて保存
- 保存するのは抽出したテキストと URL だけ（D11）

### 3.5.16 PDF・画像取り込み（S-Data-07）

- 操作
  - 「ファイルから選ぶ」（PDF）/「写真から選ぶ」「カメラで撮る」（画像）
  - 端末上でテキスト抽出（PDF）または文字認識（スキャンPDF・画像）を行う
  - 抽出結果を編集画面で確認・修正し、タイトルを付けて保存
- ファイル本体は保存しないことを画面上に明記する（D11）

## 3.6 画面状態設計（Empty / Loading / Error / Offline）

### 3.6.1 空状態（Empty）

- 自己資産が0件
  - ガイド：テンプレ入力（例文）＋最短で3件作らせる導線
- 企業が0件
  - ガイド：企業登録→すぐ想定Q&Aを作れる導線
- Q&Aが0件
  - ガイド：まず想定Q&Aを作る or 振り返り入力へ誘導
- 未完了の AI連携が0件
  - Home では表示しない

### 3.6.2 ローディング状態（Loading）

- プロンプト生成中・解析中
  - 短いインジケーター（目標2秒以内。1.2.1）
- サーバー復帰待ち（Neon のコールドスタート）
  - キャッシュ済みのデータを先に表示し、更新中であることを控えめに示す
- ネットワーク待ち
  - 再試行導線を必ず表示

### 3.6.3 エラー状態（Error）

- 解析の失敗（`partial` / `failed`）
  - エラー画面にはせず、S-AI-03 で手動修正できる状態として表示する
  - 「AIに形式どおり出力し直してもらう」ための案内文をコピーできる
- 入力不足
  - 必須フィールドを具体的にハイライト（自己資産不足、企業情報不足など）
- 保存失敗
  - 貼り戻した内容と入力内容は端末に保持し、再送できる
- 共有リンクの発行失敗
  - 再試行を案内する

### 3.6.4 オフライン（Offline）

- 画面上部に「オフライン：閲覧と下書きのみ」のバナーを表示する
- 閲覧できるもの：キャッシュ済みの自己資産・企業・ES・Q&A（最終同期日時を表示）
- できないこと：プロンプト生成・解析・保存、復習ステータスの更新、共有リンクの発行。該当ボタンは無効化し、理由を表示する
- 入力途中の下書き（面接ログ、編集中のES）は端末に保存する。オンライン復帰後は下書きがあることを表示し、ユーザーの操作で送信する（自動送信はしない。D16）

---

## 3.7 入力UX（5分で終わらせる工夫）

- テンプレ入力（質問の例、回答の型：結論→理由→具体例→学び）
- 企業/職種は候補サジェスト（過去入力から）
- 自己資産の選択は、タグでの絞り込みと前回の選択の引き継ぎで手早くする
- 面接ログは「1問ずつ追加」も「まとめて貼り付け」も可能にする
- コピー/貼り付け最適化（箇条書きを保持、改行崩れを防ぐ）
- AI連携の往復：共有シートとクリップボードの検知で、タップ数を最小にする

---

## 3.8 オンボーディング（初回価値体験までの最短導線）

- Step1: アカウント作成（メールアドレス＋パスワード）
- Step2: AI連携の仕組みの説明（ChatGPT・Gemini などのアプリを使うこと、外部に渡すデータの注意）
- Step3: 自己資産を最低3件登録（テンプレで誘導）
- Step4: 企業を1件登録（企業名＋職種だけでOK）
- Step5: 想定Q&Aのプロンプトを作り、外部AIの回答を取り込む → 価値体験
- Step6: 取り込んだ結果をQ&Aに保存して復習導線へ

## 3.9 アクセシビリティ・UI規約（MVP最低限）

- Dynamic Type（フォントサイズ変更）に追従
- 長文でも読める行間・余白（回答は折りたたみ前提）
- タップ領域は 44pt 以上を確保
- 重要CTAは画面下に固定（片手操作を想定）
- ダークモードに対応する
- VoiceOver で主要操作（AI連携の共通フロー、復習）を完了できる
