# 3. UX/UI設計

## 3.1 UX原則（このアプリの設計思想）

- 入力コスト最小：面接後の入力は「5分で終わる」ことを最優先
- 迷わせない導線：次にやるべき行動（生成/振り返り/復習）が常に1つ提示される
- 生成はブラックボックスにしない：プロンプトは見せないが、根拠（参照した自己資産）と改善点は見せる
- 失敗に強い：AI失敗/回数制限/通信断でもユーザーが行動できる代替手段を用意する
- 復習の継続性：面接直前に「軽く眺める」だけでも価値が出るUI

- S-Log-01: 面接一覧（面接単位の履歴）

- S-Log-03: 添削結果（改善案・改善版回答）
- S-QA-01: Q&Aバンク一覧
- S-QA-02: Q&A詳細
- S-QA-03: 復習UI（スワイプ/カード/単語帳）

- S-Data-03: 企業DB一覧
- S-Data-04: 企業作成/編集

- S-Set-01: 設定トップ
- S-Set-02: プラン管理（Free/Pro、制限表示、アップグレード導線）
- S-Set-03: アカウント削除

## 3.4 主要ユーザーフロー（User Flow）

### 3.4.1 事前対策フロー（想定Q&A生成）

1. Home → 「面接対策を始める」
2. 企業選択（or 企業新規作成）＋職種確認
3. 生成開始（ローディング＋進捗）
4. 生成結果表示（質問リスト＋回答）
5. 保存 → Q&Aバンクへ蓄積
6. 面接直前に復習UIで見返す

### 3.4.2 ES作成フロー（企業研究→ドラフト→推敲）

1. Home → 「ESを作成する」
2. 企業選択（なければ作成）＋提出期限設定
3. 企業研究資料の登録（URL貼り付け or PDFアップロード）
   - AIが自動要約し、特徴・求める人物像を抽出
4. ESセクション（志望動機、自己PRなど）を追加
5. AIドラフト生成
   - 参照する「自己資産」と「企業研究資料」を選択
   - AIが論理構成案（なぜこの強みとこの企業か）と本文を生成
6. エディタで修正 ⇄ AI推敲（チャット形式で「もっと具体的に」など指示）
7. 完成 → PDF出力 or テキストコピー

### 3.4.3 事後対策フロー（振り返り→添削→改善）

1. Home → 「面接を振り返る」
2. 面接選択（なければ面接作成：企業・日付・フェーズ）
3. 質問・回答を入力（複数件を連続登録できる）
4. 添削開始
5. 添削結果表示（改善点＋改善版回答案）
6. 「改善版をQ&Aに登録」→ Q&Aバンク蓄積

### 3.4.4 復習フロー（Q&Aバンク）

1. Home → 「復習する」
2. 復習対象の絞り込み（企業/タグ/未復習）
3. スワイプで確認
4. 復習ステータス更新（復習済み/要再確認）

## 3.5 画面遷移（State + Navigation）

### 3.5.1 Home（S-Home-01）

- 表示要素
  - 直近の面接（次の予定）
  - AIの「次回直すべきポイント要約」（最新の添削から抽出）
  - CTAボタン：対策を始める / 振り返る / 復習する
- 遷移
  - 対策 → S-Prep-01
  - 振り返り → S-Log-01 or S-Log-02
  - 復習 → S-QA-03

### 3.5.2 面接対策ルーム（S-Prep-01）

- 入力要素
  - 企業選択（既存 or 新規）
  - 職種入力（企業に紐づくデフォルト可）
  - 生成に使う自己資産（自動選抜 + 手動で追加/除外）
- CTA
  - 「想定Q&Aを生成」
- 遷移
  - 成功 → S-Prep-02
  - 失敗 → エラー状態（再試行/入力不足ガイド）

### 3.5.3 生成結果（S-Prep-02）

- 表示
  - 質問リスト（10問想定、可変）
  - 各質問の模範解答（折りたたみ/展開）
  - 参照した自己資産（根拠の可視化：タイトル/タグ）
- 操作
  - 保存
  - 再生成（質問だけ/回答だけ/両方）
  - ピン留め
- 遷移
  - 保存 → S-QA-01 / S-QA-02

### 3.5.4 ESプロジェクト一覧（S-ES-01）

- 表示
  - 企業名、提出期限、進捗状況（作成中/完了/提出済）
  - 「新しいESを作成」ボタン
- 遷移
  - タップ → S-ES-02

### 3.5.5 ESエディタ（S-ES-02）

- レイアウト
  - 左カラム（PC）/タブ（Mobile）：企業研究資料（URL/PDFの要約・メモ）
  - 右カラム（PC）/メイン（Mobile）：ESセクション（志望動機、自己PR...）
- 機能
  - 資料登録（URL貼り付けで自動要約）
  - セクション追加（文字数制限設定）
  - 「AIドラフト生成」ボタン
    - 使用する自己資産を選択（「学生時代に頑張ったこと」タグなど）
    - 参照する企業資料を選択（「経営理念」など）
- 遷移
  - 生成実行 → S-ES-03（推敲モード）

### 3.5.6 ES推敲（S-ES-03）

- 表示
  - 現在のドラフト文章
  - AIからのフィードバック（論理の飛躍、具体性不足など）
- チャットUI
  - 「もっと熱意を込めて」「文字数を200字減らして」などの指示
  - 修正案の提示（diff表示推奨）
- 遷移
  - 確定 → S-ES-02（エディタに戻る）
  - 完成 → 出力メニュー

### 3.5.7 面接ログ入力（S-Log-02）

- 入力
  - 質問（テキスト）
  - 回答（テキスト）
  - 任意：自己評価/補足メモ
- 操作
  - 「質問を追加」(複数件登録)
  - 「添削する」
- 遷移
  - 添削 → S-Log-03

### 3.5.8 添削結果（S-Log-03）

- 表示
  - 指摘（論理性/具体性/説得力/改善ポイント）
  - 改善版回答案
  - 使用した自己資産（参照根拠）
- 操作
  - 改善版をQ&Aとして保存
  - もう一度添削（追加情報を入れて再生成）
- 遷移
  - 保存 → S-QA-02

### 3.5.9 Q&A復習（S-QA-03）

- 表示
  - 1枚に「質問→タップで回答表示」
  - 企業名/タグ/作成日
- 操作
  - 次へ/前へ（スワイプ）
  - 復習ステータス更新（復習済み/要再確認）
  - お気に入り

## 3.6 画面状態設計（Empty / Loading / Error / Limit）

### 3.6.1 空状態（Empty）

- 自己資産が0件
  - ガイド：テンプレ入力（例文）＋最短で3件作らせる導線
- 企業が0件
  - ガイド：企業登録→すぐ生成できる導線
- Q&Aが0件
  - ガイド：まず生成 or 振り返り入力へ誘導

### 3.6.2 ローディング状態（Loading）

- AI生成中
  - スピナー＋進捗（例: 「質問を作成中」「回答を作成中」）
  - キャンセルボタン（中断してもデータ破損しない）
- ネットワーク待ち
  - 再試行導線を必ず表示

### 3.6.3 エラー状態（Error）

- AI API失敗
  - 「再試行」「入力を減らす/増やす」ガイド
  - 失敗理由（一般ユーザーに理解できる粒度）
- 入力不足
  - 必須フィールドを具体的にハイライト（自己資産不足、企業情報不足など）
- 保存失敗
  - ローカル保持（下書き）→後で再送できる設計

### 3.6.4 利用制限（Limit）

- Freeの上限到達（生成/ログ数）
  - いま何回使ったか・次回リセット日
  - Proの差分（無制限/高精度モデル/音声解放）を明示
  - アップグレード導線

---

## 3.7 入力UX（5分で終わらせる工夫）

- テンプレ入力（質問の例、回答の型：結論→理由→具体例→学び）
- 企業/職種は候補サジェスト（過去入力から）
- 自己資産は「おすすめ候補」をAIが自動選抜（タグ・類似度）
- 面接ログは「1問ずつ追加」も「まとめて貼り付け」も可能にする
- コピー/貼り付け最適化（箇条書きを保持、改行崩れを防ぐ）

---

## 3.8 オンボーディング（初回価値体験までの最短導線）

- Step1: アカウント作成
- Step2: 自己資産を最低3件登録（テンプレで誘導）
- Step3: 企業を1件登録（企業名＋職種だけでOK）
- Step4: 「ワンクリック生成」→ 価値体験
- Step5: 生成結果をQ&Aに保存して復習導線へ

---

## 3.9 アクセシビリティ・UI規約（MVP最低限）

- フォントサイズ変更に追従
- 長文でも読める行間・余白（回答は折りたたみ前提）
- タップ領域は十分確保（モバイル前提）
- 重要CTAは画面下に固定（片手操作を想定）
